# 东方光耀夜：卡牌奖励权重机制

整理自反编译的游戏代码，主要是 `GameRunController` 的 `GetRewardCards`、`CreateValidCardsPool`、`BaseCardWeight`，`Stage` / `NormalStageBase` 的权重表，以及 `LBoL.Core.Randoms` 下的 `*WeightTable`。

**示例数字的前提：** 由当前版本的卡牌数据算出，假设全部解锁，没有进游戏实测。没有特别说明时，示例都是灵梦 A 路线开局（基础法力 RRRWW，初始展品渴望鲜血的阴阳玉，可抽 89 张：灵梦牌普通 12、罕见 25、稀有 15；中立牌普通 13、罕见 14、稀有 10），稀有牌系数 0.85，没有单卡衰减。

## 1. 一次卡牌奖励的生成过程

1. 确定奖励类型和张数。
2. 按位置依次抽牌，每个位置使用不同的归属权重。
3. 每个位置先筛出符合资格的牌（奖励卡池的三条规则，以及解锁、卡包等条件），再算出每张牌的权重，按权重抽取。
4. 全部抽完后，更新稀有牌系数，并逐张判定是否直接升级。
5. 玩家选牌或放弃时，更新单卡衰减。

| 来源 | 稀有度表 | 张数 |
|---|---|---|
| 普通战斗 | 普通战斗 | 3 + 增加张数，上限 5 |
| 精英战斗 | 精英 | 同上 |
| 首领战斗 | 首领 | 同上 |
| 积木玩具（普通战斗多一次奖励） | 普通战斗 | 同上 |
| 黄油机器人（隙间小屋饮茶时） | 普通战斗 | 固定 5 |

御神签和空白卡牌各使张数 +1。

事件和战斗内生成的牌不调用 `GetRewardCards`，不属于这套流程，也不会更新稀有牌系数。

## 2. 权重公式

某张牌在某个位置的权重：

```text
权重 = 稀有度系数 × 归属系数 × 类型系数 × 发明系数 × 费用系数 × 颜色系数 × 稀有牌系数（仅稀有牌）× 单卡衰减
```

这张牌在这个位置被抽中的概率：

```text
概率 = 这张牌的权重 ÷ 这个位置所有可抽牌的权重之和
```

## 3. 每个系数的作用范围

| 系数 | 针对谁 | 什么时候变 | 会累积吗 |
|---|---|---|---|
| 稀有度系数（1 / 0.5 / 0.05 等） | 每张牌，按其稀有度查表 | 只取决于奖励类型 | 不会 |
| 归属系数 | 每张牌，按位置查表 | 只取决于位置 | 不会 |
| 类型、发明系数 | 每张牌 | 固定 | 不会 |
| 费用系数 | 每张牌 | 固定 | 不会 |
| 颜色系数 | 每张牌 | 基础法力变化时 | 不会 |
| 稀有牌系数（0.85 起） | 所有稀有牌共用一个值 | **每次卡牌奖励结算后更新一次** | 会，直到重置 |
| 下一次奖励 × 0.01 | 下一次奖励所有位置的稀有牌 | 上一次奖励出现稀有牌时生效，只持续一次奖励 | 不会 |
| 同次奖励 × 0 | 同一次奖励中后面位置的稀有牌 | 前面位置抽到稀有牌时生效 | 不会 |
| 单卡衰减 | **每张牌单独记录** | 每次选牌或放弃时 | 会，整局不重置 |

所以：

- **稀有度系数是每张牌的权重**，不是“这次奖励出某稀有度的概率”。稀有度 0.5 不代表罕见牌概率减半，还要看每种稀有度有多少张牌。
- **稀有牌系数是一局共用的状态，每次卡牌奖励更新一次。** 同一次奖励的所有位置都用同一个值，因为它在全部抽完后才更新。
- **单卡衰减只影响被跳过的那张牌**，不影响同稀有度或同颜色的其他牌。

## 4. 位置和归属：主角、其他角色、中立

| 位置 | 主角牌 | 持有展品的其他角色牌 | 中立牌 | 不重复规则 |
|---|---|---|---|---|
| 第 1 张 | 1 | 0 | 0 | 无 |
| 第 2 张 | 0.2 | 0.8 | 0 | 排除第 1 张 |
| 第 3 张 | 0 | 0 | 1 | 无需排除，归属不同 |
| 第 4、5 张 | 1 | 0.8 | 0.7 | 排除已抽到的牌 |

没有持有展品的其他角色的牌，权重是 0。

- 位置上没有符合条件的牌时，这个位置不出牌，也不会用其他牌补位。
- “主角”只看正在玩的角色。

**例 1：只有初始展品。** 第 2 张的可抽牌只有灵梦牌，全部乘 0.2 不改变相对比例，分布和第 1 张几乎一样。所以开局每次奖励是 2 张灵梦牌加 1 张中立牌。

**例 2：灵梦拿到其他角色的展品。** 其他角色牌主要占第 2 张，第 3 张依然只有中立牌。

| 展品 | 基础法力 | 第 2 张 | 第 4 张起 |
|---|---|---|---|
| 无 | RRRWW | 灵梦 100% | 灵梦 63.7%，中立 36.3% |
| 黑暗魔导书 | RRRWWB | 魔理沙 77.1%，灵梦 22.9% | 灵梦 38.8%，中立 35.1%，魔理沙 26.1% |
| 迷你八卦炉 | RRRRWW | 魔理沙 68.4%，灵梦 31.6% | 灵梦 50.0%，中立 28.4%，魔理沙 21.6% |
| 魔术扑克 | RRRWWU | 咲夜 75.1%，灵梦 24.9% | 灵梦 40.7%，中立 34.7%，咲夜 24.6% |

通感通意（玉盒）会让所有角色都算作可抽角色，并按“持有展品的其他角色”计算。

## 5. 稀有度

### 5.1 稀有度表

| 奖励类型 | 普通 | 罕见 | 稀有 |
|---|---|---|---|
| 普通战斗 | 1 | 0.5 | 0.05 |
| 精英 | 1 | 0.8 | 0.15 |
| 首领 | 0 | 0 | 1 |
| 商店 | 1 | 0.7 | 0.15 |

### 5.2 权重和实际概率不同

灵梦牌里罕见牌（25 张）比普通牌（12 张）多一倍，所以尽管罕见牌单张权重只有一半，第 1 张抽到罕见牌的概率反而略高。中立牌普通和罕见张数接近，比例就更接近权重：

| 位置 | 普通 | 罕见 | 稀有 |
|---|---|---|---|
| 普通战斗第 1、2 张 | 47.9% | 49.4% | 2.7% |
| 普通战斗第 3 张 | 62.3% | 35.6% | 2.2% |
| 普通战斗第 4 张起 | 53.1% | 44.4% | 2.5% |
| 精英第 1、2 张 | 35.5% | 58.5% | 6.0% |
| 精英第 3 张 | 49.6% | 45.3% | 5.1% |
| 精英第 4 张起 | 40.4% | 53.9% | 5.7% |

### 5.3 稀有牌的三条额外规则

1. **稀有牌系数：** 开局 0.85。一次奖励没有稀有牌时 +0.01；有稀有牌时重置为 0.85。代码里没有上限。
2. **连续保护：** 一次奖励出现稀有牌后，下一次奖励的稀有权重 × 0.01。下一次结束后恢复，除非它又出了稀有牌。
3. **同次限制：** 非首领奖励中，前面位置抽到稀有牌后，后面位置的稀有权重变为 0。

第 4、5 张是从同一张权重表一起抽的，第 3 条只在抽第 4、5 张之前检查一次。所以 5 张的奖励如果前 3 张没有稀有牌，第 4、5 张有可能同时是稀有牌，这是唯一的例外。

### 5.4 一次奖励出现稀有牌的概率

| 稀有牌系数 | 对应连续没出的次数 | 普通战斗（3 张） | 精英（3 张） |
|---|---|---|---|
| 刚出过稀有牌（0.85，× 0.01） | | 0.1% | 0.2% |
| 0.85 | 0 | 7.4% | 16.2% |
| 0.90 | 5 | 7.8% | 17.0% |
| 0.95 | 10 | 8.2% | 17.9% |
| 1.00 | 15 | 8.6% | 18.7% |
| 1.05 | 20 | 9.0% | 19.5% |
| 1.15 | 30 | 9.8% | 21.1% |
| 1.35 | 50 | 11.4% | 24.1% |

稀有牌系数涨得很慢，20 次没出也只把普通战斗的概率从 7.4% 提到 9.0%，它不是保底。

张数增加的影响（系数 0.85）：

| 张数 | 普通战斗 | 精英 |
|---|---|---|
| 3 | 7.4% | 16.2% |
| 4 | 9.7% | 21.0% |
| 5 | 12.0% | 25.5% |

### 5.5 例子：连续几次奖励

| 第几次 | 类型 | 本次稀有牌系数 | × 0.01 | 出现稀有牌的概率 | 结果 |
|---|---|---|---|---|---|
| 1 | 普通 | 0.85 | | 7.4% | 无 |
| 2 | 普通 | 0.86 | | 7.5% | 无 |
| 3 | 普通 | 0.87 | | 7.5% | 无 |
| 4 | 精英 | 0.88 | | 16.7% | 无 |
| 5 | 普通 | 0.89 | | 7.7% | 无 |
| 6 | 普通 | 0.90 | | 7.8% | **出现稀有牌** |
| 7 | 普通 | 0.85 | 是 | 0.1% | 无 |
| 8 | 普通 | 0.86 | | 7.5% | 无 |

- **所有奖励类型共用状态。** 精英没出稀有牌同样会 +0.01，精英出了稀有牌同样会重置，并让下一次普通战斗 × 0.01。
- **首领后的第一次奖励：** 首领奖励全是稀有牌，所以它总会重置系数，下一次奖励（通常是下一关第一场战斗）基本不会有稀有牌。
- **积木玩具：** 一场普通战斗连续生成两次奖励，算两次更新。如果第一次出了稀有牌，第二次就 × 0.01。

### 5.6 长期频率

用真实权重模拟 20 万次连续普通战斗奖励（3 张，不计单卡衰减和卡池变化）：

- 约 7.7% 的奖励含稀有牌，平均每 12.9 次一次。
- 间隔波动很大：中位数 10 次，90% 分位 27 次。
- 所有牌的稀有度占比：普通 52.4%，罕见 45.0%，稀有 2.6%。

### 5.7 首领奖励

首领奖励全部可抽牌都是稀有牌，所以稀有牌系数和 × 0.01 同时作用于所有牌，互相抵消，对结果没有影响。第 3 条限制也不适用，可以出多张稀有牌。谁被抽到只取决于费用、颜色和单卡衰减：

| 位置 | 权重最高 | 权重最低 |
|---|---|---|
| 第 1 张（15 张灵梦稀有牌） | 刹那亚空穴 7.9% | 出入境界 5.5% |
| 第 3 张（10 张中立稀有牌） | 不死的烈焰 12.3% | 飞光虫之巢 8.5% |

## 6. 颜色系数

```text
卡牌有颜色：颜色系数 = 1 + Σ（基础法力中该颜色的占比 − 0.5）× 0.8，最低 0.8
卡牌无颜色：颜色系数 = 0.8
```

- 求和覆盖卡牌的每一种颜色。
- 占比的分母是基础法力总数，**包含彩色和无色法力**，所以增加任何法力都会稀释其他颜色。
- 随机法力的展品不计入基础法力，不影响这个系数。
- 奖励里其实碰不到“无颜色”这一行：非道具牌中只有 3 张发明牌没有颜色，它们不进奖励。这一行只在商店生效，比如商店里的发明牌和道具牌。

**手算：** RRRWW 时，红占 3/5，红色牌 = 1 + (0.6 − 0.5) × 0.8 = 1.08；白占 2/5，白色牌 = 1 + (0.4 − 0.5) × 0.8 = 0.92；红白牌 = 1 + 0.08 − 0.08 = 1.00。

| 基础法力 | 来源 | 红 | 白 | 红白 | 第 1 张可抽 | 第 1 张抽到 红 / 白 / 红白 |
|---|---|---|---|---|---|---|
| RRRWW | 灵梦 A 开局 | 1.08 | 0.92 | 1.00 | 52 张 | 45.5% / 37.2% / 17.3% |
| RRRRWW | + 迷你八卦炉 | 1.13 | 0.87 | 1.00 | 52 张 | 47.7% / 35.0% / 17.3% |
| RRRWWB | + 黑暗魔导书 | 1.00 | 0.87 | 0.87 | 55 张 | 44.1% / 36.8% / 15.7%（另有黑 3.3%） |
| RRRWWP | + 彩色法力展品 | 1.00 | 0.87 | 0.87 | 53 张 | 45.6% / 38.2% / 16.3% |
| RRRWP | 帕秋莉事件 W → P | 1.08 | 0.80 | 0.84 | 52 张 | 49.2% / 35.0% / 15.7% |
| RRRWCC | 纯狐事件 W → CC | 1.00 | 0.80 | 0.80 | 43 张 | 55.5% / 26.6% / 17.9% |

- 颜色系数的影响不大，1.08 和 0.92 只差约 17%。**可抽牌的变化通常比系数变化影响更大**，例如纯狐事件让白色牌从 37.2% 掉到 26.6%，主要是因为付不起 WW 的牌被筛掉了。
- 多色牌的两个颜色各算一次：占比都不到一半时加起来容易触底。例如 RRRWWB 时红黑牌 = 1 + 0 − 0.267 = 0.733，取 0.8。

**例子：空白卡牌（基础法力 RRRWWP，奖励 4 张，不再要求卡牌颜色在基础法力中）**

可抽牌从 92 张（灵梦 53，中立 39）增加到 204 张（灵梦 64，中立 140）。没有的颜色占比为 0，颜色系数都是 0.8，比 1.00 和 0.87 低不了太多，所以异色牌的占比主要由张数决定：

| 位置 | 可抽 | 基础法力包含其全部颜色的牌 | 含其他颜色的牌 |
|---|---|---|---|
| 第 1、2 张 | 64 张 | 87.7% | 12.3% |
| 第 3 张 | 140 张 | 32.6% | 67.4% |
| 第 4 张起 | 204 张 | 54.1% | 45.9% |

## 7. 费用系数

只看彩色费用，与总费用无关。先取“颜色数”：卡牌颜色数和费用中不同颜色数的较大值。再取“单色最多费用”：五色中费用最多那种的点数。

| 颜色数 | 单色最多费用 → 系数 |
|---|---|
| 0 | 0.9 |
| 1 | 0–1 点 → 0.9，2 点 → 1，3 点 → 1.1，4 点 → 1.2 |
| 2 | 0 点 → 0.9，1 点 → 1，2 点 → 1.1 |
| 3 | 1.3 |

例子：

| 卡牌 | 费用 | 颜色数 | 单色最多 | 系数 |
|---|---|---|---|---|
| 灵符护体 | 1W | 1 | 1 | 0.9 |
| 二重大结界 | 3W | 1 | 1 | 0.9 |
| 妖怪破坏者 | RR | 1 | 2 | 1 |
| 刹那亚空穴 | RRR | 1 | 3 | 1.1 |
| 天仙鸣动 | WR | 2 | 1 | 1 |

灵符护体和二重大结界总费用差 2 点，系数相同。

全部可进池的非道具牌中：0.9 有 311 张，1 有 138 张，1.1 有 32 张，1.3 有 12 张。

## 8. 类型和发明牌

| 类型 | 奖励 | 商店 |
|---|---|---|
| 攻击、防御、技能、能力 | 1 | 分栏位抽取，见第 10 节 |
| 同伴 | 1 | 技能或同伴栏位 × 5 |
| 道具 | 0 | 单独栏位 |
| 状态、厄运 | 0 | 0 |

奖励里，类型之间没有权重差别。

带发明关键词的牌（黄瓜导弹、清洁能源、私家雷达）在奖励里权重为 0，在商店 × 2。

## 9. 单卡衰减

| 操作 | 影响 |
|---|---|
| 选了一张 | 同组其他牌各 × 0.9，选中的牌不变 |
| 放弃这组奖励换金币（赛钱箱可提高金额） | 同组所有牌各 × 0.85 |
| 既不选也不放弃就离开 | 不变 |

- 按卡牌 ID 记录，可累乘，整局不重置。升级与否不分开。
- 影响之后的奖励、商店和闪亮的灯泡。
- 商店买牌和看到商店的牌都不会造成衰减。

**例子：** 妖怪破坏者（权重 1.08）在第 1 张的概率：

| 经历 | 累计衰减 | 概率 |
|---|---|---|
| 从未跳过 | 1 | 4.6% |
| 被跳过 1 次 | 0.9 | 4.2% |
| 被跳过 2 次 | 0.81 | 3.8% |
| 被跳过 3 次 | 0.729 | 3.4% |
| 被跳过 5 次 | 0.59 | 2.8% |
| 被跳过 10 次 | 0.349 | 1.7% |
| 被放弃 1 次 | 0.85 | 3.9% |
| 被放弃 3 次 | 0.614 | 2.9% |

## 10. 商店

共 10 张，权重公式相同。道具以外的归属都是 1 / 0.8 / 0.7（主角 / 持有展品的其他角色 / 中立），道具是 1 / 1 / 1。传送枪补货时使用同样的权重表，并排除店内已有的牌。

| 栏位 | 张数 |
|---|---|
| 攻击 | 2 |
| 防御 | 2 |
| 技能 | 1 |
| 技能或同伴（同伴 × 5，排除上面那张技能） | 1 |
| 能力 | 2 |
| 道具 | 2 |

和奖励的区别：

- 会读取稀有牌系数和单卡衰减，但**不更新**稀有牌系数。
- 没有连续保护，也不消耗它。
- 没有同次限制，一家商店可以有多张稀有牌。
- 没有按关卡的随机升级，只有自行车这类展品的升级效果。

灵梦 A 开局：

| 栏位 | 普通 / 罕见 / 稀有 | 灵梦 / 中立 |
|---|---|---|
| 攻击 | 60.5% / 35.2% / 4.3% | 67.7% / 32.3% |
| 防御 | 50.5% / 48.2% / 1.2% | 45.0% / 55.0% |
| 技能 | 36.1% / 58.1% / 5.7% | 64.4% / 35.6% |
| 能力 | 0% / 82.4% / 17.6% | 69.8% / 30.2% |

**同伴栏位的例子：** 开局 10 条路线中，只有琪露诺的两条路线有可抽的同伴牌（5 张），这个栏位约 57% 是同伴（A 路线 56.6%，B 路线 58.5%）。其他路线开局时这个栏位全是技能。

## 11. 升级

奖励抽完后，每张普通或罕见牌单独判定一次是否直接升级，稀有牌不参与。升级不影响前面的权重。

| 关卡 | 升级概率 |
|---|---|
| 迷途竹林 | 0 |
| 玄武之泽 | 25% |
| 风神之湖 | 50% |
| 月之都城 | 50% |

通货膨胀（谜题）让概率减半。

自行车等展品的效果（每当某类牌加入牌库时升级）是单独判定的，奖励和商店都生效，稀有牌也可以。
